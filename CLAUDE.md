# CLAUDE.md — Telegram Business Bot Demo

## КТО Я (контекст для Claude)

Меня зовут Андрей. Я начинающий фрилансер на Upwork.
Строю демо-портфолио чтобы получить первые заказы.
Этот бот — мой первый portfolio item.

## ЦЕЛЬ ПРОЕКТА

Построить рабочий Telegram бот для малого бизнеса (демо для портфолио).
Тема бота: онлайн-коуч / консультант (универсально, подходит многим клиентам).

Бот должен:
1. Красиво встречать клиента на /start с кнопками меню
2. Показывать услуги, цены, информацию о коуче
3. Принимать заявку (имя, вопрос, контакт) через диалог
4. Сохранять заявки в Google Sheets
5. Слать уведомление владельцу в Telegram
6. Отвечать на свободный текст через Claude API (AI-ответы)

## СТЕК

- Python 3.11+
- aiogram 3.x (Telegram Bot API)
- anthropic (Claude API для AI-ответов)
- gspread + google-auth (Google Sheets)
- python-dotenv (для .env файлов)
- Railway.app для деплоя (потом)

## КАК РАБОТАЕТ БОТ (flow)

```
/start
  → Привет! Я помощник Анны, коуча по карьере.
  → [Услуги] [Цены] [Записаться] [Написать]

[Услуги] → список услуг с описанием
[Цены]   → прайс-лист
[Записаться] → FSM диалог:
    1. "Как вас зовут?"
    2. "Опишите ваш запрос"
    3. "Ваш контакт (телефон или @username)"
    → Сохраняем в Google Sheets
    → Уведомление владельцу
    → "Спасибо! Анна свяжется с вами в течение 24 часов"
[Написать] → "Напишите ваш вопрос, я отвечу..."
    → Claude API генерирует ответ на основе контекста
```
